# Product Charter

## 产品定义

`MobileShell` 的目标是成为一个面向个人用户的 iPhone / iPad SSH 工作台。

它不只是“手机上的 SSH 终端”，而是一个把主机、身份、会话、文件、端口转发、片段自动化和工作区上下文组织在一起的个人基础设施工具。

## 目标用户

核心用户只有一类：

- 经常连接个人服务器、家用实验室、云主机或小规模基础设施的单个用户

典型人群包括：

- 独立开发者
- 个人站长
- DevOps / SRE 的个人工作场景
- Home lab 用户
- 需要在移动设备上处理紧急运维事务的技术人员

## 核心任务

产品必须优先支持以下任务：

1. 快速找到目标主机并连接
2. 复用已保存的认证信息，避免重复输入
3. 在终端里完成日常诊断、修复与维护操作
4. 在 SFTP 中处理配置、脚本和日志文件
5. 用端口转发访问远程服务
6. 用命令片段复用重复操作
7. 在多会话之间保存上下文并快速切换

## 产品原则

### 1. Local-first

首发版本必须在没有自建后端的前提下可用。远程连接依赖 SSH 服务端，但产品本身的配置、记录、组织结构应首先能在本地稳定工作。

### 2. One-person workspace

整个产品只围绕“一个人如何管理自己的远程工作流”展开，不为团队协作预埋复杂权限模型。

### 3. Host-centered

用户的心智中心是 `Host`，而不是一次性的连接字符串。所有认证、标签、片段、工作区、日志与转发规则都应围绕主机上下文组织。

### 4. Progressive power

基础连接体验必须简单，但产品要允许用户逐步进入更强的自动化与组织能力，例如片段、工作区、模板、继承配置。

### 5. Safe by default

Known Hosts、凭证存储、删除确认、错误提示、状态恢复必须可靠；不能为了“看起来像专业工具”而牺牲安全感和恢复能力。

## 版本边界

### 首个可发布版本

首发版必须具备：

- 本地主机库
- 分组、标签、搜索
- SSH 终端会话
- SFTP 浏览与基本文件操作
- 身份、密钥、密码与证书管理
- Known Hosts 信任流程
- 端口转发
- 命令片段
- 本地工作区、会话历史与日志基础能力

### 首发后增强版本

首发后可以继续扩展：

- 工作区模板
- Startup snippets
- Group / Host 继承能力完善
- 命令自动补全
- 日志书签
- Terminal 主题与字号继承
- 环境变量注入
- 更完整的会话恢复

### 暂不纳入产品主线

以下内容不应进入当前产品主线：

- Team vault
- 多成员协作
- 实时共享或多人终端
- 组织级别计费与后台
- SAML / SSO
- 审计合规报表
- 企业权限与审批流

## 阶段划分

### Phase A：Daily Driver 基座

目标：让单个用户可以稳定把它当成日常远程工作入口。

### Phase B：Personal Power Features

目标：增强自动化、组织性和终端体验，接近 Termius Pro 个人版的高频能力。

### Phase C：Selective Premium Personal

目标：只在明确需要时加入个人版增强能力，但当前阶段不进入开发主线。

当前决定：

- 暂时不考虑个人云同步
- 在没有新的产品决策前，不为同步能力分配实现优先级

## 非目标

本项目当前不追求：

- 完整复制 Termius 全平台能力
- 一次性覆盖所有网络协议
- 先做账号系统再做本地体验
- 先做云同步再做可靠本地持久化
- 为未来团队版预先引入复杂抽象

## 成功标准

如果一个用户可以在 iPhone / iPad 上完成下面这些事情，而不觉得自己在使用“缩水版 SSH 工具”，则说明方向正确：

- 保存并组织几十台主机
- 复用身份与密钥快速连接
- 同时维持多个终端会话
- 在 SFTP 中处理常见文件任务
- 保存常用命令片段并复用
- 在应用重启后保留主要上下文
- 通过工作区与标签快速回到某个任务现场
